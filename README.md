# Linux und GitHub Actions

Linux-Befehle und automatisierte Abläufe Schritt für Schritt praktisch lernen.

## Kursinhalte

Der Kurs richtet sich an Einsteigerinnen und Einsteiger und umfasst drei aufeinander aufbauende Teile:

1. [Teil 1: Grundlagen, Dateien, Textsuche und Shell-Skripte](Linux%20%2B%20GitHub%20Actions,%20Teil%201.md)
2. [Teil 2: Jobs, Dateien, Zeitpläne und ein Abschlussprojekt](Linux%20%2B%20GitHub%20Actions,%20Teil%202.md)
3. [Teil 3: Matrix-Builds, Secrets, wiederverwendbare Workflows und Fehlerbehandlung](Linux%20%2B%20GitHub%20Actions,%20Teil%203.md)

### Grundlagen

- [YAML-Grundlagen](YAML-Grundlagen.md): Aufbau und Syntax der Workflow-Dateien.
- [Markdown-Grundlagen](Markdown-Grundlagen.md): Eine verständliche Projekt-README erstellen.
- [Git-Grundlagen](Git-Grundlagen.md): Änderungen, Commits, Branches und Pull Requests über GitHub.

Die Grundlagenmodule begleiten den Kurs. Lies [YAML-Grundlagen](YAML-Grundlagen.md) vor den ersten Workflow-Dateien. Richte dein eigenes Lern-Repository nach der Vorbereitung in Teil 1 ein. Erstelle anschließend mit [Markdown-Grundlagen](Markdown-Grundlagen.md) eine README für dein Lern-Repository und verwende [Git-Grundlagen](Git-Grundlagen.md), bevor du weitere Änderungen committen oder Branches verwenden sollst. Für alle drei Teile verwendest du dasselbe Lern-Repository. Lege die im Kurstext gezeigten Dateien dort an und führe die Workflows aus. Die Lizenzdateien bleiben im Kurs-Repository; Git Flow brauchst du für dein Lern-Repository nicht.

## Voraussetzungen

Du brauchst ein GitHub-Konto und ein öffentliches Repository. Die Übungen verwenden GitHub Actions. Materialien für Codeberg Actions und GitLab CI sind für einen späteren Ausbau geplant.
