# Beispielprojekt: Log-Auswertung

> Lernmaterial: CC BY 4.0 (siehe `LICENSE-CONTENT.txt`). Alle Angaben in dieser Vorlage sind Beispieldaten.

## Zweck

Dieses Beispielprojekt wertet vorbereitete Logdateien aus und übt grundlegende Linux-Befehle sowie GitHub Actions.

## Voraussetzungen

- Ein GitHub-Konto
- Ein eigenes Lern-Repository mit aktivierten GitHub Actions
- Schreibzugriff auf das Lern-Repository

## Erste Schritte

1. Lies die Kursanleitung und erstelle dein Lern-Repository.
2. Lege die im Kurs beschriebenen Beispieldateien an.
3. Öffne den Tab **Actions** und starte den vorgesehenen Workflow manuell.
4. Prüfe die Ausgaben im Laufprotokoll.

## Wichtige Dateien

- `.github/workflows/`: Workflow-Dateien für GitHub Actions
- `daten/server.log`: Beispieldaten für die Log-Auswertung
- `skripte/`: Beispielskripte, sofern sie in der jeweiligen Lektion erstellt wurden

## Ergebnisse prüfen

Vergleiche die Ausgaben mit den Kontrollpunkten der jeweiligen Kurslektion. Lauf- und Beispieldaten können je nach Übung variieren.
